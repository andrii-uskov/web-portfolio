# Expense Tracker (Python)

A simple console app to track expenses. Built with Python.

## Features
- Add expenses with amount and category
- Data is saved in a CSV file
- Show totals by category and overall
- Input validation: asks again if the amount is not a number

## How to run
```
python main.py
```

## What I learned
- Functions, loops and dictionaries in Python
- Reading and writing CSV files
- Error handling with try/except

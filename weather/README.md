# Weather App

A simple weather app built with HTML, CSS and JavaScript.
Enter a city name and get the current temperature and wind speed.

**Live demo:** https://andrii-uskov.github.io/web-portfolio/weather/

## Features
- Search weather by city name
- Shows current temperature and wind speed
- Error messages for unknown cities or connection problems
- Search by pressing Enter or the button

## Technologies
- HTML
- CSS
- JavaScript (fetch, async/await)
- [Open-Meteo API](https://open-meteo.com/) (no API key needed)

## What I learned
- Working with a public API using `fetch`
- Handling asynchronous code with `async/await`
- Error handling with `try/catch`
- Publishing a project with GitHub Pages

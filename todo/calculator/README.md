# Simple Calculator 🧮

A clean and responsive web-based calculator built with Vanilla JavaScript. 

## 🚀 Features
*   **Basic Math Operations:** Addition, subtraction, multiplication, and division.
*   **Clear & Delete:** Ability to clear the entire display or delete the last entered character.
*   **Decimal Support:** Works with floating-point numbers.
*   **Responsive Design:** Looks great on both desktop and mobile devices.
*   **Keyboard Support (Optional):** *[Write this only if you added keyboard support, otherwise delete this line]*

## 🛠️ Technologies Used
*   **HTML5** — for the structure of the calculator.
*   **CSS3 (Grid & Flexbox)** — for the layout and modern UI design.
*   **JavaScript (ES6)** — for the calculation logic, DOM manipulation, and event handling.

## 💡 How to Use
1. Clone this repository or download the files.
2. Open `index.html` in your web browser.
3. Alternatively, view the live demo here: [Live Demo](https://andrii-uskov.github.io/web-portfolio/todo/calculator/)
